# Dental clinic landing page (Arabic, RTL)

A single-page sample website for a small dental clinic, built with plain HTML, CSS and a little JavaScript. No frameworks.

- Arabic right-to-left layout
- Mobile-first, works down to ~360px wide
- Sections: hero, key facts, price list, why us, FAQ accordion, opening hours, WhatsApp booking
- Fast: three small files plus one web font

The clinic name, doctor, prices and numbers are made up for demo purposes. Replace the text, colors and WhatsApp number to fit a real client.

Live demo: https://welcome789000-sys.github.io/clinic-landing/

نموذج تصميم لعرض الأعمال. قبل/بعد والأسعار تجريبية، وصور الحالات أماكن فاضية. رقم الواتساب بيتحط في `WHATSAPP_NUMBER` داخل `script.js`.
